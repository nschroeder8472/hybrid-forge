# Task: six painted item icons

Make a set of six inventory icons for a fantasy role-playing game, in a rich
painted style — the look of hand-painted game art, with light, shading and
material detail, not flat vector shapes. They should read clearly at small size
and look like one set: same style, same lighting direction, same framing.

The six items:

- `sword` — a knight's longsword
- `shield` — a heraldic kite shield
- `potion` — a glass flask of glowing red potion
- `scroll` — a rolled parchment scroll with a wax seal
- `ring` — a gold ring set with a large blue gem
- `helmet` — a steel great helm

## Pinned output

- `icons/<item>.png` for each of the six: an RGBA PNG, exactly 256 x 256,
  transparent background, the item centred with a small transparent margin.
- `icons/sheet.png`: the six icons side by side in the order above, 1536 x 256.

Whatever produces the icons stays in the repository. Commit the work to git.
